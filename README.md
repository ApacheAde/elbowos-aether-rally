# Aether Rally

Full-colour Python 3 neon **volley / pong** arcade for **ElbowOS**. Keep the plasma orb in play against a laggy CPU paddle. Rallies stack score. Lime vs orange on a teal night court.

Featured account: [x.com/ElbowOS](https://x.com/ElbowOS)

## Play

```bash
python3 -m pip install -r requirements.txt
python3 aether_rally.py --play
```

- **Left / A** — slide your lime paddle left
- **Right / D** — slide right
- **R** — reset scores
- **Esc** — quit

Python 3 + pygame. Full-colour neon arcade, not a terminal toy.

## Record a 9:16 reel

```bash
ELBOWOS_RECORD=1 python3 aether_rally.py
# or
python3 aether_rally.py --record
```

Writes `AETHER_RALLY_ElbowOS.mp4` — 1080×1920, 15s, 30fps, H.264 yuv420p.
